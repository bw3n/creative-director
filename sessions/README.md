# Sessions

Scrap-session notes.

When you and the agent do a focused session — pulling ads, writing cards, debating tensions, drafting principle extractions — write the session here. Format is free; the goal is for future-you (or future-the-agent) to read the note and know:

- What was added or changed in this session
- What was rejected and why
- What patterns the session surfaced that aren't yet in the corpus
- What to do next

Sessions are not part of the agent's runtime corpus. The agent does not load them on demand. They are session-history, not skill-assets.

When you start a new session, create a new file with the date as the filename:

```
sessions/2026-08-09-three-tbwa-copenhagen-cards.md
```
