# Examples

Worked examples showing how the skill's four jobs actually operate against corpus cards.

Each example follows this shape:

1. The user's input (brief, idea, work to critique)
2. The skill's load order — what cards or principles get read
3. The output in the format defined by `SKILL.md` Layer 1
4. A short note on what the corpus contributed to the output

Examples are not cards. They are demonstrations of the skill *using* the corpus. They live alongside the corpus, indexed here for future reference.

When you write a new example, copy the file structure from `example-against-schulstad.md` and substitute your input.
